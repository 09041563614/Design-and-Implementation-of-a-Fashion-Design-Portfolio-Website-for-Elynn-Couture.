# Design-and-Implementation-of-a-Fashion-Design-Portfolio-Website-for-Elynn-Couture.
Project Description
Elynn Couture is a simple, responsive fashion design portfolio website created to showcase fashion designs, introduce the brand, display services and provide contact information for potential clients.

Features

- Home section
- About section
- Fashion portfolio/gallery
- Services section
- Contact information
- Responsive mobile-friendly design
- Simple navigation

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Download and extract the project ZIP file.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. View the website in your browser.

Project Scope

Frontend only. No PHP, database or admin dashboard.
